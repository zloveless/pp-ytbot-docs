# Documentation for Eerie's YouTube Integration Bot

Eerie's bot is a custom YouTube chat integration bot for the [@pseudoposse](https://youtube.com/@pseudoposse) *7 Days to Die* streams. It lets viewers interact with the game in real time — similar to Twitch Integration — by spending accumulated points to trigger in-game events.

You can **help** the streamers with heals and buffs, **hinder** them with debuffs and injuries, or **unleash chaos** by spawning zombies and hostile creatures directly on top of them.

## Patch Notes

What's changed in Project Z since launch, newest first.

- Failed spawn commands now automatically retry, and refund your points if every retry comes up empty

- **Stank**, **Hot Zone**, and **Cold Snap** debuffs are back after last patch's mix-up
